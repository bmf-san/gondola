# Gondola

A simple and flexible reverse proxy written in Go.

## Features

- Lightweight and fast execution
- Simple YAML configuration
- Static file hosting with fallback
- Custom error pages
- Virtual host routing
- Graceful shutdown
- Hot configuration reload (SIGHUP)
- Access log reopen for rotation (SIGUSR1)
- Detailed access logs (nginx-compatible): JSON or Apache formats
- TLS/SSL support (TLS 1.2+)
- Trace ID support
- Timeout control
